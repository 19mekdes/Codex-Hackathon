 FixProof AI — From Error to Evidence

An AI-powered debugging assistant that helps developers understand errors, review proposed fixes, and verify solutions.
 About
FixProof AI aims to simplify debugging by providing AI-generated root-cause explanations, proposed code corrections, and suggested test cases—all in one workspace.
Our key idea: AI suggestions are not proof. We aim to distinguish proposed fixes from actual test results.
 Key Features
- AI-powered error analysis
- Root-cause explanations
- Proposed code fixes
- Suggested test cases
- Transparent verification results
 🛠️ Tech Stack
- Frontend: React, TypeScript, Vite
- Backend: Python, Django REST Framework
- AI: OpenAI API
- Database: SQLite, if needed

 Target Audience
Software engineering and computer science students, programming learners, professional developers, and software development teams.

 Project Status
MVP in progress.** Python is our initial focus, with support for additional programming languages planned for the future.
